# P307-Stellar-and-Planetary-Astrophysics
Repository of assignments for P307

Assignments 1 & 2 are just to familiarize the student with python. The assumed knowledge for much of the rest of the course is a basic knowledge of python syntax and the ability to plot things with matplotlib. 

These assignments are to work with the real data on astrophysical objects and help interpret them. Each assignment is a mix of coding and interpretation questions. 

**Assignment 3 - Celestial Coordinates**

An assignment to use the astropy coordinates and time modules to determine if an chosen object is visible at a given observatory. 

**Assignment 4 - Black Body Radiation**

Plot the black body curve and the Wien's Law. 

**Assignment 5 - The Bohr Atom**

This assignment connects the obserational result of the Fraunhofer lines to the discrete electron orbits of the Bohr atomic model.
